SQL Injection Demo

Learn how attackers can manipulate database queries

About SQL Injection

SQL Injection is a code injection technique that exploits vulnerabilities in an application's software by inserting malicious SQL statements into an entry field for execution. This occurs when user input is not properly sanitized before being passed to SQL queries.

Common Attack Vectors:

  • Authentication Bypass: Using ' OR '1'='1 to always return true in login queries
  • Data Extraction: UNION SELECT statements to retrieve sensitive information from other tables
  • Data Modification: UPDATE or DELETE statements to alter or destroy data
  • Command Execution: Advanced techniques to execute system commands on the database server

Why It Happens: Applications that dynamically build SQL queries by concatenating strings with user input, without using prepared statements or parameterized queries.

Potential Impacts: Unauthorized data access, data theft, data corruption, complete database compromise, and in severe cases, control of the underlying server. SQL injection has been responsible for major data breaches affecting millions of users.

Vulnerability
  • Bypass authentication
  • Extract sensitive data
  • Modify or delete data
  • Execute admin operations
Prevention
  • Use parameterized queries
  • Validate and sanitize input
  • Use prepared statements
  • Limit database permissions
How the Attack Works

SQL injection occurs when attackers manipulate input fields to alter the intended SQL query structure. For example, entering special characters like quotes or semicolons can break out of the intended query and execute arbitrary SQL commands.

Normal Query
SELECT * FROM users WHERE username = 'admin' AND password = 'password'
Injected Query
SELECT * FROM users WHERE username = '' OR '1'='1' -- ' AND password = 'anything'

The injected query always returns true ('1'='1'), bypassing authentication completely.
