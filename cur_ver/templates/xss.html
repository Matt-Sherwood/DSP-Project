About XSS (Cross-Site Scripting)

Cross-Site Scripting (XSS) is a web security vulnerability that allows attackers to inject malicious client-side scripts into web pages viewed by other users. This occurs when web applications fail to properly sanitize user input before displaying it in HTML pages.

How XSS Works: Attackers inject malicious JavaScript code into trusted websites. When other users visit these pages, their browsers execute the injected scripts, potentially stealing cookies, session tokens, or other sensitive information.

Types of XSS:

  • Reflected XSS: Malicious script is reflected off a web server (e.g., in search results or error messages)
  • Stored XSS: Malicious script is permanently stored on the target server (e.g., in databases, comments, or user profiles)
  • DOM-based XSS: Vulnerability exists in client-side code rather than server-side code

Potential Impacts: Session hijacking, cookie theft, keylogging, phishing, website defacement, and malware distribution. XSS remains one of the most common web application vulnerabilities according to OWASP Top 10.

Vulnerability
  • Stealing cookies and session tokens
  • Defeating CSRF protection
  • Performing actions on behalf of users
  • Redirecting users to malicious sites
Prevention
  • Escape user input
  • Use Content Security Policy
  • Validate and sanitize input
  • Use safe templating
How the Attack Works

XSS attacks work by injecting malicious JavaScript code into web pages that other users will view. The browser executes this code as if it were part of the legitimate website.

Normal HTML Output
<div>Hello, user!</div>
XSS-Infected Output
<div>Hello, <script>alert('XSS!')</script>!</div>

When the browser renders the infected HTML, it executes the malicious script, potentially stealing cookies or performing actions on behalf of the user.

Vulnerable Code
if request.method == 'POST':
    user_input = request.form.get('input', '')
    return f"<h1>XSS Demo</h1>...{user_input}..."
Safe Alternative
from markupsafe import escape

if request.method == 'POST':
    user_input = request.form.get('input', '')
    return f"<p>Your input: {escape(user_input)}</p>"
