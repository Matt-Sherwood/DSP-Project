What is XSS?

Cross-Site Scripting (XSS) happens when untrusted input is treated as browser-executable markup or JavaScript.

In plain terms: attacker input crosses a trust boundary and lands in an unsafe browser sink (like innerHTML), where it can execute as code.

How and why it works
  1. Server receives user input.
  2. Server embeds that input into the page response.
  3. Browser parses the response as HTML and JavaScript.
  4. If input lands in an unsafe context, browser executes attacker logic.

Why: browsers are parsers/interpreters. They do exactly what the markup tells them, unless you force input to remain data (escaped text).
