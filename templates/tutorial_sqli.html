What is SQL Injection?

SQL Injection happens when user input is treated as SQL syntax instead of plain data values.

If your app builds queries by string concatenation, an attacker can modify query logic, bypass checks, or extract extra data.

How and why it works
  1. App receives username/password.
  2. App concatenates those values into query text.
  3. Database parses that text as SQL grammar.
  4. Injected operators/comments can alter the intended condition.

Why: SQL engines execute structured syntax, and concatenation lets attacker-controlled syntax enter that structure.
