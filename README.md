# Web Vulnerabilities Demo

Comprehensive demonstration of common web vulnerabilities for educational purposes: XSS, SQL Injection, and Web Scraping.

## Installation

1. Install Python 3.11+ from https://python.org/
2. Install required packages: `pip install flask flask-sqlalchemy beautifulsoup4 requests`

## Running

1. Navigate to the `flask_demo` directory
2. Run `python db_init.py` to initialize the database
3. Run `python app.py` to start the Flask server on http://localhost:5000
